# 📦 MCSManager  
**Gestor ligero y moderno para servidores Minecraft Java**  
Windows • Vanilla • Forge • Fabric • NeoForge  

---

## 🚀 ¿Qué es?

MCSManager es un **ejecutivo portátil** que te permite:

- Crear servidores **Vanilla, Forge, Fabric o NeoForge** en **1 clic**.  
- Instalar / desinstalar **mods** sin tocar carpetas.  
- Editar **server.properties**, **whitelist**, **puertos**, **RAM**, etc. con interfaz oscura.  
- Arrancar / parar el servidor **graficamente**.  
- **Exportar mod-packs** para compartir.  

**Sin consolas, sin líneas de comando, sin complicaciones.**

---

## 🎮 Uso rápido

1. Ejecuta `MCSManager.exe`.  
2. **Crea servidor** → elige versión, tipo y RAM → **Crear**.  
3. **Arranca** con el botón **START**.  
4. **Invita amigos**: comparte tu IP y puerto (por defecto `25565`).

---

## 🛠️ Funciones

| Característica | Descripción |
|----------------|-------------|
| **4 motores** | Vanilla, Forge, Fabric, NeoForge (últimas versiones) |
| **Mods** | Búsqueda, instalación y desinstalación **en 1 clic** (Modrinth API) |
| **Configuración visual** | Dificultad, gamemode, PvP, online-mode, puerto, chunks, etc. |
| **Whitelist** | Añade / quita usuarios con **avatar 3D** (Mojang API) |
| **Exportar mods** | Genera `.zip` con los `.jar` actuales para compartir. |
| **Java auto-check** | Detecta si falta Java 21 y te da **enlace oficial**. |
| **Interfaz oscura** | Diseño limpio, **temas Minecraft**, iconos personalizados. |
